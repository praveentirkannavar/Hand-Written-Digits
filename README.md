# Handwritten Digit Recognition

## 📌 Project Overview

This project uses Deep Learning to recognize handwritten digits (0–9) using the MNIST dataset. A neural network built with TensorFlow and Keras is trained to classify digit images.

##  Technologies Used

* Python
* TensorFlow & Keras
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🚀 Project Workflow

1. Load the MNIST dataset.
2. Preprocess and normalize image data.
3. Build and train a neural network.
4. Predict handwritten digits.
5. Evaluate model performance.
6. Visualize results using a confusion matrix.

## ▶️ How to Run

1. Clone this repository.
2. Open `HandWrittenDigits.ipynb` in Jupyter Notebook.
3. Run all cells sequentially.
4. View the model predictions and evaluation results.

## 📊 Results

The model predicts handwritten digits from 0 to 9 and evaluates its performance on test data using accuracy and a confusion matrix.
